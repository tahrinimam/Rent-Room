🏠 Rent-Room

Rent-Room is a room rental website designed to help users easily explore available rooms, check rental details, and find suitable accommodation.

🚀 Features
🏠 Browse available rooms
🔍 Search rooms by location
🏷️ Filter rooms based on requirements
📋 View room details
👤 User Login & Registration
📱 Responsive design
🎨 Clean and modern UI
📞 Easy booking/contact option
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Responsive Web Design
LocalStorage
